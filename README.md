# PLC Flow Control PoC

基于 Siemens S7-1200 + FastAPI + Vue 3 的小规模 PLC 流控监控系统概念验证项目。

## 项目概述

目前处于 Demo / PoC 阶段，面向工业现场流量、压力、阀门状态等数据的实时采集、监控与异常告警，计划接入 1～2 台 PLC 或模拟设备，暂未投入正式生产。

## 技术架构

- **PLC**：Siemens S7-1200
- **通信协议**：OPC UA / Modbus TCP
- **后端**：Python + FastAPI
- **前端**：Vue 3
- **实时通信**：WebSocket
- **数据存储**：TimescaleDB（规划）
- **缓存与消息**：Redis / MQTT（可选）

## 核心功能

1. PLC 流量、压力、阀门状态等点位实时采集
2. FastAPI REST API 与 WebSocket 数据推送
3. Vue 3 实时监控看板和历史趋势展示
4. 通信断线自动重连与异常告警
5. 运行日志记录与设备状态监控

## 断线重连机制

- 通信超时时间：3 秒
- 重试策略：指数退避（1/2/4/8/16 秒）
- 连续 3 次失败触发异常告警
- 断线后标记采集数据失效，禁止控制指令写入
- 恢复连接后重新校验设备状态与采集点位

## Devin Bot 分工

Devin Bot 负责：

- PLC 通信适配器开发
- FastAPI 后端接口实现
- Vue 3 监控界面开发
- 断线重连及告警逻辑实现
- 自动化测试与模拟设备联调
- Docker 部署配置及开发文档维护

PLC 底层控制、安全联锁及生产设备操作由人工负责审核和验证。
